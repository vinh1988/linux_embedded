Sensor Gateway Processing:

  1. Connection Manager receives temperature data from sensor nodes
  2. Data Manager calculates running average over 5 samples
  3. Data Manager detects if temperature exceeds thresholds
  4. Storage Manager saves all data to SQLite database
  5. Log Process records temperature events (too hot/cold)
